1. Нарушение Single Responsibility Principle (SRP)
Проблема: Компонент делает всё сразу
Решение: Разделить на независимые компоненты

2. Смешение логики и представления
Проблема: Логика фильтрации и форматирования в шаблоне и методах
Решение: Вынести бизнес-логику в composables

3. setTimeout + watch
Проблема: setTimeout с задержкой в watch
Решение: Вынести в отдельный composable с четким API

4. Мутация пропса в updateQuery()
Проблема: props.filters.query = event.target.value
Решение: emit для отправки события родителю

5. Перезапись пропса products
Проблема: products.value = filtered
Решение: использовать computed для фильтрации, удалить локальную переменную

6. Мутация пропса
Проблема: props.products.push({ id: 999 })
Решение: использовать emit

7. Фильтрация и сортировка в шаблоне
Проблема: .filter().sort() выполняются при каждом рендере, нет key
Решение: +key, вынос в computed

8. Уточнить необходимость debounce
Проблема: Отсутствие debounce
Решение: Добавить

9. Случайная задержка
Проблема: непредсказуемое время
Решение: константа, фикса

10. Конфликт имен
Проблема: const products и props.products
Решение: ренейминг

11. Магическое число 1.2
Проблема: Магическое число 1.2
Решение: вынести к константу + нейминг

12. Поле available
Проблема: Не фильтруется поле available
Решение: Добавить p.available в фильтрацию

13. Отсутствие :key
Проблема: Нет ключа в v-for
Решение: Добавить :key="product.id"

14. Кривой регистр
Проблема: toUpperCase в одном месте, toLowerCase в другом
Решение: Использовать toLowerCase везде

15. Нет обработки пустого результата
Проблема: При пустом результате пустой экран
Решение: Добавить сообщение "Ничего не найдено"

16. Смешение стилей
Проблема: Инлайн стили вперемешку со scoped
Решение: Вынести в единый scoped блок

17. Утечка памяти
Проблема: При каждом изменении query создается новый setTimeout
Решение: Использовать clearTimeout перед созданием нового таймера + при дестройе компонента 

18. v-model вместо ручного @input
Проблема: @input+value
Решение: v-model предпочтительней
